Гидролиз солей

Среда раствора, ионы, уравнения гидролиза

На пальцах

Гидролиз без формул и зубрёжки

Что такое гидролиз?

Когда соль растворяется в воде, она распадается на ионы (это мы уже знаем из диссоциации). Но иногда эти ионы начинают взаимодействовать с водой, образуя обратно слабый электролит. Вот это и есть гидролиз.

По сути, гидролиз — процесс, обратный нейтрализации. Нейтрализация: кислота + основание = соль + вода. Гидролиз: соль + вода = частично «воскрешает» слабую кислоту или слабое основание.

Аналогия: «Боксёрский матч»

Представь, что кислота и основание — два боксёра. Они дрались (реакция нейтрализации) и оба «упали» — получилась соль (ничья). Но тут приходит вода-рефери и начинает «оживлять» того боксёра, который был слабее.

Кто был слабым — того вода и «воскрешает» обратно. А сильный так и лежит в виде ионов, ему вода не нужна.

Отсюда главное правило:

«Слабый гидролизуется» Гидролизу подвергается тот ион, который образован СЛАБЫМ электролитом

Определение среды: кто побеждает?

Вода — судья в споре между кислотой и основанием. Если кто-то из них «слабак» — вода берёт его сторону и «добивает», образуя слабый электролит обратно. Среда раствора зависит от того, кто «побеждает»:
1. Сильный + сильный = ничья. Среда нейтральная (pH ~ 7). Гидролиз НЕ идёт. Пример: NaCl (NaOH + HCl).
2. Сильное основание + слабая кислота = побеждает основание. Среда щелочная (pH > 7). Гидролиз по аниону. Пример: Na₂CO₃.
3. Слабое основание + сильная кислота = побеждает кислота. Среда кислая (pH < 7). Гидролиз по катиону. Пример: NH₄Cl.
4. Слабый + слабый = непредсказуемо (кто слабее). Гидролиз по обоим ионам. Пример: CH₃COONH₄.

Примеры «на пальцах»

Na₂CO₃ (сода)

Образована: NaOH (сильное основание) + H₂CO₃ (слабая кислота).

Слабый здесь — кислота (H₂CO₃). Значит, гидролизуется анион CO₃²⁻ (он «от кислоты»). Вода «воскрешает» слабую кислоту, при этом выделяется OH⁻ → среда щелочная.

CO₃²⁻ + H₂O ⇌ HCO₃⁻ + OH⁻ OH⁻ в растворе → щелочная среда

NH₄Cl (нашатырь)

Образована: NH₃·H₂O (слабое основание) + HCl (сильная кислота).

Слабый здесь — основание. Значит, гидролизуется катион NH₄⁺. Вода «воскрешает» слабое основание, при этом выделяется H⁺ → среда кислая.

NH₄⁺ + H₂O ⇌ NH₃·H₂O + H⁺ H⁺ в растворе → кислая среда

NaCl (поваренная соль)

Образована: NaOH (сильное основание) + HCl (сильная кислота).

Оба сильные — никто не «слабак». Гидролиз НЕ идёт. Среда нейтральная.

Ступенчатый гидролиз

Если ион многозарядный (CO₃²⁻, PO₄³⁻, Al³⁺, Fe³⁺), гидролиз идёт ступенчато — по одной ступени за раз. В обычных условиях преимущественно идёт первая ступень.

Аналогия: Вода «воскрешает» слабого боксёра не сразу целиком, а по частям — сначала руку поднимет, потом голову... Полностью «оживить» удаётся редко (только при нагревании или разбавлении).
Na₂CO₃: CO₃²⁻ + H₂O ⇌ HCO₃⁻ + OH⁻ 1-я ступень (основная). 2-я: HCO₃⁻ + H₂O ⇌ H₂CO₃ + OH⁻ (пренебрежимо мала)

Необратимый (полный) гидролиз

Некоторые соли, образованные слабым основанием И слабой кислотой, гидролизуются полностью — они вообще не могут существовать в водном растворе!

Al₂S₃ + 6H₂O → 2Al(OH)₃↓ + 3H₂S↑ Сульфид алюминия полностью разлагается водой
Признак полного гидролиза: продукты «уходят» из раствора — осадок (↓) и газ (↑). Равновесие полностью смещается вправо.

Определение гидролиза

Гидролиз солей — обменное взаимодействие ионов соли с молекулами воды, приводящее к образованию слабого электролита и изменению pH среды.

Гидролиз — процесс, обратный нейтрализации:

Нейтрализация: кислота + основание → соль + H₂O
Гидролиз: соль + H₂O ⇌ кислота + основание Обратимый процесс (⇌), кроме случаев полного гидролиза

Правило: гидролизу подвергается тот ион соли, который образован слабым электролитом. Ион, образованный сильным электролитом, с водой не взаимодействует.

Типы гидролиза

Тип соли Среда pH Гидролиз
Сильн. осн. + сильн. кисл. Нейтральная ≈ 7 Не идёт
Сильн. осн. + слаб. кисл. Щелочная > 7 По аниону
Слаб. осн. + сильн. кисл. Кислая < 7 По катиону
Слаб. осн. + слаб. кисл. Зависит от Kд ≈ 7 По обоим ионам

Гидролиз по аниону

Соль образована сильным основанием и слабой кислотой. Анион (от слабой кислоты) реагирует с водой.

Na₂CO₃ (карбонат натрия)

Образована: NaOH (сильн.) + H₂CO₃ (слаб.). Гидролизуется анион CO₃²⁻.

Ионное: CO₃²⁻ + H₂O ⇌ HCO₃⁻ + OH⁻
Молекулярное: Na₂CO₃ + H₂O ⇌ NaHCO₃ + NaOH Среда щелочная (OH⁻), pH > 7

CH₃COONa (ацетат натрия)

Образована: NaOH (сильн.) + CH₃COOH (слаб.). Гидролизуется анион CH₃COO⁻.

CH₃COO⁻ + H₂O ⇌ CH₃COOH + OH⁻ Среда щелочная (OH⁻), pH > 7

K₂SiO₃ (силикат калия)

Образована: KOH (сильн.) + H₂SiO₃ (слаб.). Гидролизуется анион SiO₃²⁻.

SiO₃²⁻ + H₂O ⇌ HSiO₃⁻ + OH⁻ Среда щелочная (OH⁻), pH > 7

Гидролиз по катиону

Соль образована слабым основанием и сильной кислотой. Катион (от слабого основания) реагирует с водой.

NH₄Cl (хлорид аммония)

Образована: NH₃·H₂O (слаб.) + HCl (сильн.). Гидролизуется катион NH₄⁺.

NH₄⁺ + H₂O ⇌ NH₃·H₂O + H⁺ Среда кислая (H⁺), pH < 7

CuSO₄ (сульфат меди)

Образована: Cu(OH)₂ (слаб.) + H₂SO₄ (сильн.). Гидролизуется катион Cu²⁺.

Cu²⁺ + H₂O ⇌ CuOH⁺ + H⁺ Среда кислая (H⁺), pH < 7

AlCl₃ (хлорид алюминия)

Образована: Al(OH)₃ (слаб.) + HCl (сильн.). Гидролизуется катион Al³⁺.

Al³⁺ + H₂O ⇌ AlOH²⁺ + H⁺ Среда кислая (H⁺), pH < 7, первая ступень

Гидролиз по обоим ионам

Соль образована слабым основанием и слабой кислотой. Оба иона реагируют с водой.

CH₃COONH₄ + H₂O ⇌ CH₃COOH + NH₃·H₂O Среда близка к нейтральной (зависит от соотношения констант)

Необратимый (полный) гидролиз

Если оба продукта уходят из раствора (↓ и ↑), гидролиз идёт до конца:

Al₂S₃ + 6H₂O → 2Al(OH)₃↓ + 3H₂S↑ Полный гидролиз — необратимый (→, не ⇌)
Cr₂S₃ + 6H₂O → 2Cr(OH)₃↓ + 3H₂S↑ Ещё пример полного гидролиза
Важно: Al₂S₃, Cr₂S₃, Al₂(CO₃)₃, Fe₂(CO₃)₃ — эти соли не существуют в водном растворе, так как полностью гидролизуются. Их нельзя получить обменной реакцией в растворе!

Константа гидролиза Kг

Гидролиз — обратимый процесс, и у него есть своя константа равновесия:

Kг = Kw / Ka Для гидролиза по аниону (соль сильн. осн. + слаб. кисл.)
Kг = Kw / Kb Для гидролиза по катиону (соль слаб. осн. + сильн. кисл.)
Логика: чем слабее кислота (или основание), тем меньше её Ka → тем больше Kг → тем сильнее идёт гидролиз. Слабый «боксёр» легче «воскрешается» водой!

Степень гидролиза h

Показывает, какая доля соли подверглась гидролизу:

h = √(Kг / C) = √(Kw / (Ka · C)) C — молярная концентрация соли

pH раствора соли (гидролиз по аниону)

pH = 7 + ½ · pKa + ½ · lg C pKa = −lg Ka. pH > 7 (щелочная среда)

pH раствора соли (гидролиз по катиону)

pH = 7 − ½ · pKb − ½ · lg C pKb = −lg Kb. pH < 7 (кислая среда)
Пример: CH₃COONa, C = 0,1 M. Ka(CH₃COOH) = 1,75·10⁻⁵, pKa ≈ 4,76.
pH = 7 + ½·4,76 + ½·lg(0,1) = 7 + 2,38 − 0,5 = 8,88 (щелочная среда).

Факторы, усиливающие гидролиз

  • Нагревание — смещает равновесие вправо (эндотермический процесс)
  • Разбавление — увеличивает концентрацию воды, смещает равновесие
  • Удаление продуктов — выпадение осадка, выделение газа
