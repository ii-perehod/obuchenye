# Промпт: Генерация счётного тренажёра

Этот промпт — шаблон для любой кодящей ИИ. Подставь свою тему, формулы, задачи — получишь готовый HTML-тренажёр с теорией, квизом и калькулятором.

---

## Как пользоваться

1. Скопируй весь текст ниже (от `--- НАЧАЛО ПРОМПТА ---` до `--- КОНЕЦ ПРОМПТА ---`)
2. Замени всё в `{{двойных скобках}}` на свои данные
3. Отправь в Claude / ChatGPT / другую ИИ
4. Получи готовый HTML-файл

## --- НАЧАЛО ПРОМПТА ---

Создай одностраничный HTML-тренажёр (один файл, без зависимостей, vanilla JS) по теме: **{{ТЕМА}}**.

### СТРУКТУРА ФАЙЛА

Файл содержит 5 экранов, переключаемых JS-функцией `showScreen(id)`:

1. **Меню** (`menuScreen`) — 3 кнопки: Теория на пальцах, Теория по-взрослому + Квиз, Калькулятор
2. **Теория «на пальцах»** (`theorySimple`) — простые аналогии из жизни
3. **Теория «по-взрослому»** (`theoryFormal`) — формулы с разбором + квиз на понимание
4. **Калькулятор-тренажёр** (`calcScreen`) — задачи на вычисление
5. **Результаты** (`calcResults`, `quizResults`) — итоги с процентами

### БЛОК 4: КАЛЬКУЛЯТОР-ТРЕНАЖЁР

Это главная часть. Ученик решает задачи, собирая выражение из кликабельных элементов.

#### Принцип работы:
- На экране — карточка «Дано» с кликабельными значениями
- Если в задаче есть формула/уравнение — коэффициенты тоже кликабельные
- Ученик кликает по данным → они появляются в строке выражения
- Между ними ставит операторы кнопками: + − × ÷ ^ ( ) | | .
- Кнопка `| |` — модуль (Math.abs): первый клик открывает, второй закрывает
- Нажимает `=` → выражение вычисляется и сравнивается с ответом
- Если верно — зелёный фидбек, объяснение, кнопка «Дальше»
- Если неверно — красный фидбек, правильный ответ, объяснение, кнопки «Попробовать снова» / «Пропустить»

#### Кнопки калькулятора (в один ряд):
```
[10] [+] [−] [×] [÷] [^] [(] [)] [||] [.] [⌫] [AC] [=]
```
Кнопка `10` нужна потому что все остальные числа ученик берёт из условия задачи кликом. Число 10 — единственное, которое часто нужно набирать вручную (деление на 10, степени). Если в твоей теме есть другие «служебные» числа — добавь их вместо или рядом с 10.

**НЕТ цифровых кнопок 0-9!** Все числа берутся из условия. Клавиатура поддерживает цифры для десктопа.

#### Два блока задач:
1. **С формулой-подсказкой** (первые ~10 задач) — в поле `find` написана формула с подставленными буквами
2. **Без формулы** (следующие ~20 задач) — только «Найти v = ?», формулу нужно вспомнить самому

Блоки перемешиваются ВНУТРИ себя, но идут по порядку: сначала все с формулой, потом все без.

#### Формат данных задач:
```javascript
const calcWithFormula = [
    {
        type: '{{тип задачи}}',      // для группировки
        title: 'Текст задания',       // что нужно найти
        reaction: {                    // формула/уравнение (кликабельные части)
            parts: [
                { type: 'coef', val: '2' },       // коэффициент — КЛИКАБЕЛЬНЫЙ (оранжевый)
                { type: 'sub',  val: 'H₂' },      // вещество/переменная (просто текст)
                { type: 'text', val: ' + ' }       // разделитель
            ]
        },
        given: [                       // кликабельные данные задачи
            {
                label: 'название на РУССКОМ языке', // НЕ буква, а слово!
                value: 0.5,                          // число для вычисления
                unit: 'моль/л',                      // единица измерения
                display: '0.5'                       // как показать на экране
            }
        ],
        find: 'v = k · [H₂]² · [O₂] = ?',  // С ФОРМУЛОЙ для первого блока
        answer: 0.0045,                       // правильный ответ
        tolerance: 0.0005,                    // допуск (±)
        explanation: 'HTML пошагового решения с <b>выделением</b> чисел'
    }
];

const calcNoFormula = [
    // Та же структура, но find: 'Найти скорость v = ?' (БЕЗ формулы)
];
```

#### КРИТИЧНО — подписи данных:
- В поле `label` — РУССКОЕ НАЗВАНИЕ, а не обозначение!
- ❌ `k`, `[H₂]`, `γ`, `t₁`
- ✅ `константа скорости`, `концентрация водорода`, `температурный коэффициент γ`, `начальная температура`
- Ученик должен сам догадаться, какая буква соответствует какому значению

#### КРИТИЧНО — объяснения:
- Пошаговые, с промежуточными результатами
- Каждое число из условия выделено `<b>жирным</b>`
- Если задача на отношение (v₂/v₁) — показать дробь:
```html
<div style="font-family:Consolas,monospace; line-height:2;">
    v₂ = k · (2·[A])² · [B]<br>
    <div style="border-top:2px solid #888; display:inline-block; padding-top:2px;">
        v₁ = k · [A]² · [B]
    </div>
</div>
```
Числитель (v₂) СВЕРХУ, знаменатель (v₁) СНИЗУ — чтобы дробь v₂/v₁ читалась правильно.

#### Работа над ошибками:
После основного раунда — автоматически показать все пропущенные задачи снова.
- Если ученик нажал «Попробовать снова» и решил верно → задача засчитана, повтора не будет
- Если нажал «Пропустить» → задача идёт в повтор
- Во время повтора — значок ⟳ перед номером задачи
- Счёт считается от общего числа задач

#### Проверка ответов:
```javascript
// Собрать выражение из токенов
const expr = calcTokens.map(t => t.value).join('')
    .replace(/\^/g, '**')     // степень
    .replace(/−/g, '-')       // Unicode минус → ASCII
    .replace(/×/g, '*')       // умножение
    .replace(/÷/g, '/');      // деление
// Вычислить через Function (безопасный eval)
const result = Function('"use strict"; return (' + expr + ')')();
// Сравнить с допуском
Math.abs(result - task.answer) <= task.tolerance
```
