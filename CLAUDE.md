# CLAUDE.md — Проект obuchenye

Квизы и тренажёры для сына (20 лет, особенности развития). Всё на чистом HTML/CSS/JS — никаких фреймворков, никаких зависимостей, один файл = один тренажёр.

## Стек

- Vanilla HTML5 + CSS3 + JavaScript (ES6+)
- Один файл на тренажёр, без сборки
- Репо: https://github.com/ii-perehod/obuchenye
- GitHub Pages: https://ii-perehod.github.io/obuchenye/
- Git push: `git -c http.proxy="" -c https.proxy="" -c http.sslBackend=schannel push`

## Правила UI

- НЕТ `max-height` на текстовых контейнерах — текст виден целиком, страница скроллится
- Каждое задание: `shuffle` порядка при старте
- Трекинг ошибок: массив неверных → кнопка "🔁 Повторить ошибки (N)" если есть
- Повтор только неверных, в перемешанном порядке, с `roundBadge` "Раунд N"
- Цикл повтора пока все не верны

## Правила содержания квизов

- НЕ спрашивать даты (если это не история)
- НЕ спрашивать "Кто открыл / предложил..." — это олимпиадный формат
- Учёные важны ТОЛЬКО если закон носит их имя
- Вопросы проверяют понимание сути, не запоминание фактов

## Структура тренажёра (orbital-trainer.html)

Эталонный файл для орбиталей. Содержит:
- **Режим 0** — "Заполни элемент": случайный элемент, перетащи стрелки
- **Режим 1** — "Свободное заполнение": любая конфигурация
- **Режим 2** — "Валентность": автозаполнение, зелёное свечение валентных электронов, клик на ↑↓ → анимация возбуждения (только периоды 1-3), счётчик валентности

SUBSHELLS включают до 5p (Z=1-54). Для d-элементов: валентность = неспаренные (n-1)d + ns.

## Логика валентности металлов (orbital-trainer.html, режим 2)

**Распаривание электронов происходит ТОЛЬКО когда есть акцептор с распаренными местами:**

- Спаренные s-электроны → распариваются и один уходит в свободную d-орбиталь (или p)
- Это не "подготовка", а реальное состояние при образовании соединения
- Условие: электроны идут к электроотрицательному элементу

**Элементы с возбуждением (нужно показывать анимацию):**
- **Ca** (Z=20): 4s² распаривается, один электрон → 3d (в реальных соединениях)
- **Sr** (Z=38): 5s² → 4d (аналогично Ca)
- **Al** (Z=13): 3s² может распариваться → валентность 1 и 3 (оставить как есть)

**Элементы БЕЗ автоматического возбуждения:**
- **Be** (Z=4): в основном состоянии 2s², возбуждается ТОЛЬКО при необходимости → валентность II
- **Mg** (Z=12): ❌ НЕ ВОЗБУЖДАТЬ АВТОМАТИЧЕСКИ. В основном 3s², валентность II (спаренные электроны отдаёт сразу). Возбуждение НЕ показывать.

**Исключение в примечаниях (VAL_EXPLAIN):**
- Для Mg: удалить строку о "всегда возбуждается"
- Оставить как обычный s-элемент (валентность II без распаривания в grid'е)
